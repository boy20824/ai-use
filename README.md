# AI 使用管理

前端工作台：選擇案件類別、閱讀相關文件與填寫步驟，再把草稿檔留在這個分頁。登入使用示範角色。案件送審、分派與結案尚未接上。

畫面資料來自前端示範模組。程式不會對 API 發送請求，不會用 `v-html`，也不會把上傳檔案的內容送到伺服器。

## 技術棧

- Vite
- Vue 3
- TypeScript
- Tailwind CSS
- Vue Router
- Pinia
- ESLint 與 Prettier
- pnpm

## 環境

- Node.js 22 或以上
- pnpm 10

## 安裝與啟動

```bash
pnpm install
cp .env.example .env
pnpm dev
```

開發伺服器位址以終端機輸出為準，預設是 `http://localhost:5173`。

## 指令

| 指令             | 作用                                |
| ---------------- | ----------------------------------- |
| `pnpm dev`       | 啟動開發伺服器                      |
| `pnpm build`     | 執行型別檢查並產出正式建置          |
| `pnpm preview`   | 預覽正式建置                        |
| `pnpm typecheck` | 只做型別檢查                        |
| `pnpm lint`      | 執行 ESLint，並用 Prettier 檢查格式 |

## 環境變數

`.env.example` 只包含 `VITE_API_BASE_URL`。複製成 `.env` 後可改成本機 API 位址。

程式只判斷這個值是否已填寫，用來在總覽顯示「已讀取」或「未設定」。不會向該位址送出任何請求。

請勿把權杖、密碼或其他密鑰放進這個變數。Vite 會把以 `VITE_` 開頭的變數打包進前端。`.env` 已列入 `.gitignore`。

## 路由

| 路徑              | 頁面                             |
| ----------------- | -------------------------------- |
| `/login`          | 選擇示範身分                     |
| `/`               | 總覽                             |
| `/categories`     | 案件類別                         |
| `/categories/:id` | 類別工作台：文件、步驟、草稿上傳 |
| `/drafts`         | 我的草稿                         |
| `/access`         | 角色與權限對照                   |

未登入時，工作台路由會回到 `/login`。`/cases` 與 `/personnel` 會轉到案件類別。

## 示範身分

登入頁沒有密碼。可選三種身分，結果只留在目前分頁的記憶體：

| 身分       | 可以做的事               |
| ---------- | ------------------------ |
| 類別承辦   | 瀏覽類別，並加入草稿紀錄 |
| 系統管理員 | 與承辦相同，並可對照權限 |
| 唯讀檢視   | 只能閱讀類別、文件與步驟 |

重新整理後需重新選擇身分。本機加入的草稿紀錄也會消失，示範草稿會回到初始清單。

上傳時只保存檔名、大小與類型。程式不會讀取檔案內容，也不會把檔案送到後端。

## 目錄

```text
src/
  components/    共用介面元件
  config/        應用名稱與環境變數讀取
  data/mock.ts   示範類別、草稿、角色與帳號
  layouts/       深色側邊欄與上方列
  router/        路由與登入守衛
  stores/        Pinia 狀態
  views/         各路由頁面
```

## 範圍

- 沒有後端、沒有登入 API、沒有真實權限判斷。
- 沒有案件紀錄或人員名冊。類別、文件與草稿都是虛構資料。
- 沒有使用 `v-html`。
- 沒有密鑰、連線字串或私人憑證。
